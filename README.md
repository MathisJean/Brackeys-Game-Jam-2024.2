**My first game jam entry** — a short platformer built for Brackeys Game Jam 2024.2, theme: *"Calm Before the Storm."*

## The game
 
A short platformer: navigate through spikes to grab an orb. The moment you grab it, the calm ends — wind kicks in and makes movement harder, and lightning starts periodically striking the ground around you.
 
## Context
 
This was my first completed game jam. It's short and rough around the edges, but it's a finished, playable submission built under real jam time pressure — which is its own kind of useful constraint to learn from.
